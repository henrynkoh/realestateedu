# RealEstateEdu Tutorial

This hands-on tutorial will guide you through the key features of RealEstateEdu, demonstrating how to analyze properties and complete educational modules.

## Part 1: Exploring Real Estate Listings

### Step 1: Browse Available Listings

1. Open RealEstateEdu in your web browser
2. Click on "Listings" in the top navigation bar
3. Browse through the available properties
4. Notice the key information displayed on each listing card:
   - Price
   - Address
   - Number of bedrooms and bathrooms
   - Square footage
   - Property type

### Step 2: Apply Filters

1. Look at the filter panel at the top of the listings page
2. Try filtering by:
   - Setting a minimum price of $400,000
   - Setting a maximum price of $700,000
   - Selecting "3" for minimum bedrooms
   - Selecting "Single Family" for property type
3. Notice how the listings update to match your criteria
4. Try clearing filters to see all listings again

### Step 3: View Listing Details

1. Choose an interesting property and click on its listing card
2. On the detailed view page, observe:
   - The property images
   - Detailed information (price, bedrooms, bathrooms, square footage)
   - Full description
   - Financial data (taxes, insurance, etc.)
3. Scroll down to see all available information

## Part 2: Running an Investment Analysis

### Step 1: Access the Analysis Tool

#### Option A: From a Listing
1. While viewing a listing detail page, click the "Analyze Investment" button
2. Notice how the property details are automatically loaded into the analysis form

#### Option B: Direct Access
1. Click on "Analysis" in the top navigation bar
2. See the default property values in the analysis form

### Step 2: Enter Property Data

If you're using the direct access method, enter the following property details:
1. Purchase Price: $500,000
2. Estimated Monthly Rent: $2,500
3. Annual Property Taxes: $5,000
4. Annual Insurance Cost: $1,200
5. Annual Maintenance Cost: $1,800
6. Mortgage Interest Rate: 6.75%

### Step 3: Review Analysis Results

1. After entering data, the analysis results will automatically update
2. Review the three investment scenarios:
   - **Buy-to-Rent**: Shows ROI, monthly cash flow, annual expenses, and profit
   - **Flip**: Shows ROI, total expenses, and estimated profit
   - **Long-term Hold**: Shows ROI, cash flow, expenses, and profit (including appreciation)
3. Compare the metrics side by side
4. Check the chart at the bottom to visually compare key metrics

### Step 4: Try Different Values

1. Change some of the input values to see how they affect the results
2. Try:
   - Increasing the purchase price to $600,000
   - Decreasing the estimated monthly rent to $2,200
   - Reducing the mortgage interest rate to 5.5%
3. Observe how these changes impact each investment scenario
4. Notice which scenario becomes more or less favorable with each change

## Part 3: Completing an Education Module

### Step 1: Access the Education Portal

1. Click on "Education" in the top navigation bar
2. If prompted, sign in with your account
   - For this tutorial, you can use:
   - Email: demo@example.com
   - Password: password123
3. Browse the available education modules
4. Note any progress indicators on modules you've already started

### Step 2: Start a Module

1. Choose the "Real Estate Basics" module
2. Click "Start Module" (or "Continue" if you've started it before)
3. Read through the content, paying attention to key concepts and definitions

### Step 3: Take a Quiz

1. After reading the module content, click "Take Quiz"
2. Answer each question by selecting the option you believe is correct
3. After answering all questions, click "Submit Quiz"
4. Review your score and correct answers
5. Take note of any questions you got wrong for future study

### Step 4: Track Your Progress

1. Return to the main Education page
2. Notice the updated progress bar on the "Real Estate Basics" module
3. See your quiz score displayed on the module card
4. Try starting another module ("Property Analysis Fundamentals")
5. Go through the same process of reading content and taking the quiz

## Part 4: Putting It All Together

### Step 1: Choose a Property

1. Go back to the Listings page
2. Find a property that interests you for potential investment
3. Open its detailed listing page

### Step 2: Analyze Investment Potential

1. Click "Analyze Investment" from the listing detail page
2. Review the pre-populated property data
3. Adjust any values as needed (e.g., expected rent, maintenance costs)
4. Examine the results for all three investment scenarios
5. Determine which scenario offers the best potential return for this property

### Step 3: Apply Your Education

1. Think about the concepts you learned in the educational modules
2. Consider questions like:
   - Does this property's cash flow meet the 1% rule?
   - How do the property taxes compare to the average in the area?
   - What is the cap rate, and is it favorable?
3. Make an informed assessment based on both the analysis results and your educational knowledge
