## Introduction

RealEstateEdu is a comprehensive platform designed to help users make informed real estate investment decisions through data analysis and education. This manual provides a detailed guide to all features and functionalities of the application.

### Key Features

- **Real-time Listings**: Access and filter the latest NWMLS real estate listings
- **Investment Analysis**: Evaluate properties based on ROI, cash flow, and more
- **Interactive Education**: Learn real estate concepts through structured modules and quizzes
- **Progress Tracking**: Monitor your learning progress across educational modules

## Getting Started

### System Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection
- Device with 1280 x 720 or higher screen resolution (for optimal experience)

### Creating an Account

1. Visit the RealEstateEdu homepage at [https://realestateedu.com](https://realestateedu.com)
2. Click on "Sign In" in the top-right corner of the navigation bar
3. Select "Sign Up" on the authentication page
4. Enter your email address and create a password
5. Click "Sign Up" to create your account
6. Check your email for a verification link (if email verification is enabled)

### Logging In

1. Navigate to the "Sign In" page
2. Enter your email and password
3. Click "Sign In" to access your account

## Real Estate Listings

The Listings page provides access to current real estate listings from the NWMLS database.

### Browsing Listings

1. Navigate to the "Listings" page from the main navigation
2. Scroll through the grid of available properties
3. Click on any listing card to view detailed information

### Filtering Listings

Use the filter panel at the top of the listings page to narrow down properties:

1. **Price Range**: Set minimum and maximum price values
2. **Bedrooms**: Specify the minimum number of bedrooms
3. **Bathrooms**: Specify the minimum number of bathrooms
4. **Property Type**: Filter by property category (Single Family, Condo, etc.)

### Listing Details

When viewing a specific listing, you can:

1. View property photos (gallery)
2. See key details (price, bedrooms, square footage, etc.)
3. Read the full property description
4. Review financial information (taxes, estimated rent, etc.)
5. Click "Analyze Investment" to perform a feasibility analysis on this property

## Feasibility Analysis

The Analysis tool helps evaluate the investment potential of properties across different scenarios.

### Running an Analysis

1. Navigate to the "Analysis" page from the main navigation
2. Enter property details:
   - Purchase price
   - Estimated monthly rent
   - Annual property taxes
   - Annual insurance cost
   - Annual maintenance cost
   - Mortgage interest rate
3. View the analysis results for different investment scenarios

### Understanding Results

Analysis results are presented for three main scenarios:

1. **Buy-to-Rent**: Evaluates the property as a long-term rental investment
   - ROI (Return on Investment)
   - Monthly cash flow
   - Annual expenses
   - Annual profit

2. **Flip**: Analyzes the property as a short-term renovation and resale opportunity
   - ROI
   - Estimated profit
   - Total expenses (renovation, holding costs, etc.)

3. **Long-term Hold**: Assesses the property as a long-term appreciation investment
   - ROI (including both rental income and appreciation)
   - Monthly cash flow
   - Annual expenses
   - Annual profit (cash flow plus estimated appreciation)

### Comparison Chart

The bar chart at the bottom of the analysis page provides a visual comparison of key metrics across all scenarios, helping you identify the most promising investment strategy.

## Education Portal

The Education section offers structured learning modules on real estate investment topics.

### Accessing Modules

1. Navigate to the "Education" page from the main navigation
2. Browse available modules (requires login)
3. Click on a module card to start or continue a module

### Module Structure

Each education module includes:

1. **Content**: Informative text with key concepts and explanations
2. **Quiz**: Interactive questions to test your understanding
3. **Progress Tracking**: Visibility of your completion status and scores

### Taking Quizzes

1. After reviewing a module's content, click "Take Quiz"
2. Answer each question by selecting the appropriate option
3. Click "Submit Quiz" when complete
4. View your score and correct answers
5. Return to modules or retake the quiz as needed

### Tracking Progress

The Education dashboard displays your progress across all modules:

- Module completion status
- Quiz scores
- Visual progress bars

## Account Management

### Updating Profile Information

1. Click on your profile icon in the top-right corner
2. Select "Profile" from the dropdown menu
3. Update your information as needed
4. Click "Save" to apply changes

### Changing Password

1. Navigate to your profile settings

3. Enter your current password
4. Enter and confirm your new password
5. Click "Update Password"

### Deleting Account

1. Go to your profile settings
2. Select the "Advanced" tab
3. Click "Delete Account"
4. Confirm your decision in the prompt

## Troubleshooting

### Common Issues

1. **Can't Log In**
   - Check that you're using the correct email and password
   - Ensure that your account has been verified (check email)
   - Try resetting your password
   
2. **Listings Not Loading**
   - Check your internet connection
   - Clear your browser cache
   - Disable browser extensions that might interfere
   
3. **Analysis Charts Not Displaying**
   - Ensure JavaScript is enabled in your browser
   - Try a different browser
   - Check that you've entered valid property data

### Getting Help

If you encounter problems not covered in this manual:

1. Check the [FAQ section](#faq) below
2. Contact support at support@realestateedu.com
3. Submit a help request through the "Help" link in the footer

## FAQ

**Q: Is real MLS data being used in the application?**
A: Yes, when configured with valid NWMLS API credentials. Without credentials, the application uses mock data for demonstration purposes.

**Q: How accurate is the feasibility analysis?**
A: The analysis uses standard real estate investment formulas but simplified for educational purposes. For critical investment decisions, consult with a financial advisor.

**Q: Can I save properties for later review?**
A: This feature is coming soon. Currently, you can bookmark pages in your browser or take notes separately.

**Q: Are the educational modules created by real estate professionals?**
A: Yes, all educational content is developed by experienced real estate investors and educators, though the current version contains sample content for demonstration.

**Q: Is my personal information secure?**
A: Yes, all personal data is encrypted and stored securely using Supabase's security infrastructure.

**Q: Can I use RealEstateEdu on my mobile device?**
A: Yes, the application is responsive and works on mobile devices, though the desktop experience offers the most comprehensive functionality.

**Q: How often is listing data updated?**
A: With valid NWMLS API credentials, listing data is refreshed daily. Mock data does not update automatically.
